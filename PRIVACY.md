# Privacy notes

## Notas de privacidad

This document describes the privacy-relevant behavior currently visible in the repository. It is not a legal privacy notice for every distribution channel.

Este documento describe el comportamiento relevante para la privacidad que actualmente se observa en el repositorio. No sustituye un aviso legal de privacidad para todos los canales de distribución.

## Data used / Datos utilizados

Mnemis may process:

- Media URLs or local media references supplied by the user.
- Network requests needed to resolve or play remote media.
- A generated peer ID for a KoalaSync connection.
- Optional room username, room password, room ID, and media title.
- Playback state such as play/pause, position, and synchronization sequence numbers.

Mnemis puede procesar:

- URLs multimedia o referencias a archivos locales proporcionadas por el usuario.
- Solicitudes de red necesarias para resolver o reproducir medios remotos.
- Un peer ID generado para una conexión de KoalaSync.
- Nombre opcional, contraseña, ID de sala y título del medio.
- Estado de reproducción como play/pause, posición y números de secuencia.

## Sharing / Compartición

When joining KoalaSync, room and playback data is sent to the configured KoalaSync server and may be visible to peers in the same room. Remote media providers may also receive requests from the device, subject to their own policies.

Al unirte a KoalaSync, los datos de sala y reproducción se envían al servidor configurado y pueden ser visibles para los participantes de la misma sala. Los proveedores de medios remotos también pueden recibir solicitudes del dispositivo según sus propias políticas.

Mnemis should not be used to bypass access controls, authentication, geographic restrictions, or the terms of a third-party service. Users are responsible for the content they access and share.

Mnemis no debe usarse para evadir controles de acceso, autenticación, restricciones geográficas ni términos de servicios de terceros. Cada usuario es responsable del contenido que accede y comparte.

## User controls / Controles del usuario

Users can choose whether to open a remote source, join a room, provide optional room metadata, or disconnect from KoalaSync. Clear a room connection when it is no longer needed.

Las personas pueden decidir si abren una fuente remota, se unen a una sala, proporcionan metadatos opcionales o se desconectan de KoalaSync. Desconecta la sala cuando ya no la necesites.
