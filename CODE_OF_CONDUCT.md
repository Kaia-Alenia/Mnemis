# Code of Conduct

## Código de conducta

We want Mnemis to be a welcoming, respectful, and technically constructive project for everyone.

Queremos que Mnemis sea un proyecto acogedor, respetuoso y técnicamente constructivo para todas las personas.

Expected behavior includes:

- Respectful communication and good-faith collaboration.
- Useful, specific technical feedback.
- Respect for different backgrounds, abilities, identities, and perspectives.
- Protecting private information and reporting security issues privately.

El comportamiento esperado incluye:

- Comunicación respetuosa y colaboración de buena fe.
- Comentarios técnicos útiles y específicos.
- Respeto por distintos contextos, capacidades, identidades y perspectivas.
- Protección de la información privada y reportes de seguridad por canales privados.

Harassment, discrimination, threats, doxxing, sexualized attention, spam, and deliberate disruption are not acceptable.

El acoso, la discriminación, las amenazas, la exposición de datos personales, la atención sexualizada, el spam y la interrupción deliberada no son aceptables.

Report conduct concerns privately to the project maintainers through the repository contact channel. Do not use public issues for sensitive reports.

Reporta problemas de conducta de forma privada a los responsables mediante el canal de contacto del repositorio. No uses issues públicos para reportes sensibles.
