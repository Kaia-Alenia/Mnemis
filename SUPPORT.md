# Support

## Soporte

Use GitHub issues for reproducible bugs and feature requests. Use discussions or the project's official community channel for usage questions when available.

Usa GitHub Issues para errores reproducibles y solicitudes de funciones. Usa Discussions o el canal oficial de la comunidad para preguntas de uso cuando esté disponible.

## What to include / Qué incluir

- Mnemis version or commit.
- Android version and device model.
- Source type: local file, direct URL, YouTube, web player, or KoalaSync.
- Exact steps to reproduce.
- Expected and actual behavior.
- Relevant sanitized logs.

- Versión o commit de Mnemis.
- Versión de Android y modelo del dispositivo.
- Tipo de fuente: archivo local, URL directa, YouTube, reproductor web o KoalaSync.
- Pasos exactos para reproducirlo.
- Comportamiento esperado y real.
- Logs relevantes y sanitizados.

Do not post passwords, cookies, access tokens, private room IDs, personal data, or private media links. Security issues belong in [SECURITY.md](SECURITY.md), not in a public issue.

No publiques contraseñas, cookies, tokens, IDs privados de salas, datos personales ni enlaces privados de medios. Los problemas de seguridad deben seguir [SECURITY.md](SECURITY.md), no un issue público.
