# Image / Animation / Sprite Viewer

Phase 17 provides a dedicated image-oriented viewer.

Supported concepts:

- pixel-perfect rendering
- integer zoom
- transparency checkerboard
- pixel grid
- pixel coordinate inspection
- RGBA/HEX inspection
- animated image playback
- animation speed
- loop
- sprite-sheet mode
- configurable frame size
- configurable rows/columns
- frame range
- FPS
- frame navigation
- direct animation without exporting GIF

This phase intentionally does not implement video/audio playback.
