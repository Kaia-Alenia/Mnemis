# Library Query Layer

This layer queries media without depending on QML.

Supported:

- Root-scoped queries
- Folder-scoped queries
- Recursive queries
- Direct-folder queries
- Text search
- Media type filtering
- Sorting
- Pagination
- Count queries

The query layer is read-only.

It does not:

- Index files
- Modify media
- Own UI state
- Play media
- Generate thumbnails
